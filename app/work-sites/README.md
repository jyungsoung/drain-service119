# 시공현장 등록 기준

실제 현장만 등록합니다. `cases-data.ts`의 `WORK_CASE_TEMPLATE`을 복사해 `workCases` 배열에 추가하면 목록, 상세페이지, 해당 지역 대표페이지와 사이트맵에 함께 반영됩니다.

등록할 때 필요한 정보:

1. 지역: 시·구·동, 건물 형태
2. 증상: 배수 지연, 역류, 악취, 반복 막힘 등
3. 진단: 확인한 배관 구간과 실제 원인
4. 장비: 현장에서 실제 사용한 장비
5. 결과: 작업 후 확인한 배수 상태와 관리 안내
6. 사진: 작업 전, 진단 중, 작업 후 사진 3~6장

고객 이름, 동·호수, 전화번호, 차량번호처럼 개인을 식별할 수 있는 정보는 사진과 글에서 제외합니다.
